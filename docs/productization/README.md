# 产品化 · 阶段 0（产品定义与契约）

> 状态：**草稿**（2026-11-10 起草，阶段 0 计划 11-11 ～ 11-17 收口）。
> 本目录只放平台层的定义和契约，可以公开；业务场景、席位所在节点、指标基线放在私有的台仓库，不进本仓。

## 为什么有这一组文档

工作台市场从「登记 + 门户 + 自产台 + SOP」走向产品化。阶段性终局是：

- **体验版**：以模拟数据为准的完整界面，不是最终的产品和样式；
- **agent DSH 实例预演**：用真实的 DSH 实例（装 a2a-net 与 superagent）走一遍「下达 → 席位执行 → 产物入台 → 人审 → 沉淀」。

产品化不是只改界面。市场是 agent 组织的人用入口，它和 DSH、A2A、superagent、ygl-trees 的接缝决定了体验上限，所以阶段 0 先把这些接缝写成契约。
