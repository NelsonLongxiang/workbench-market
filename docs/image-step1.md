## 二、这一步做什么、不做什么

做：

- 数据视图：数据集加一种列类型 `image`，格子里存一个图片链接；`table` 和 `records` 两个块把它显示成缩略图，点开看原图。
- 报告：模板第 2 版加 `image` 节点，图片链接来自模板参数、字段或数据行；冻结时只记链接加哈希（D5）。
- 代取：一条服务端路由，按引用判（Q9）：来源属于这个台、读者能读它、它确实引用了这条链接，三条都满足才由市场去取图交给浏览器。

不做：上传；表单（form 块）填图；图片编辑；报告导出 PDF（现在本来就没有 PDF 服务）；按台隔离图库目录。

## 三、链接和配置

- 新环境变量 `WM_IMAGE_GALLERY_BASE`（可选）：图库的地址前缀，例如 `http://127.0.0.1:8090/`。按仓库红线写进 README。
  - 配了：格子里可以写图库内的**相对路径**（不以 `http://`、`https://` 开头的），代取时拼在这个前缀后面。图库搬家只改配置，不改数据。
  - 没配：只收完整的 `http(s)://` 链接，相对路径写入时报错。
- 格子的值：文本，最长 2048 个字符；只认两种写法——`http://` 或 `https://` 开头的完整链接，或（配了前缀时）不含 `..` 段、不以 `/` 开头的相对路径。其余写入时报 400「图片须为 http(s) 链接或图库内的相对路径」。
- 浏览器拿到的永远是市场自己的地址：`/api/bench-views/<台>/image?u=<格子里的原值，URL 编码>&view=<视图>[&version=<版本>][&p.<名字>=<值>…]`，来源参数照取数（render）的写法，浏览器渲染视图时用的是哪组就带哪组。

## 四、代取路由

`GET /api/bench-views/:bench/image?u=…&view=…`。**不新增动作**：路由照这组路由的注册写法声明 `{ action: 'bench-store.render', kind: 'read', statusNotVerdict }`，处理里自己判（第 1 条），动作清单、预设、角色矩阵都不改。

1. **判权：按引用判（Q9，D5 已定）**，顺序固定：`who(req, res)` 认人（跨站 403、管理口令 403、匿名 401）→ 取台登记 → `may(actor, 'bench-store.render', 台)`（读者能读这个台的视图），不成立回 403 → 台没登记的，判过权才回 404 → 照请求带的 `view`、`version`、`p.*` 渲染**这个台**的那份视图，结果里某个 `image` 列确实有这条链接（来源属于这个台、确实引用），否则回 403（视图不存在、版本不对、参数不合都算没引用）→ 之后才查缓存、去取图。三条任一不满足都是同一个 403，**不发起任何外部请求，缓存命中也照判**。**不能用 `allowActor`**（它按单个动作判、失败直接 403）。报告作来源（`report-read` 的读者从报告页看图）随报告的 `image` 节点在 PR C 加，判法同样三条：报告属于这个台、读者能读这份报告、报告冻结内容里有这条链接。
2. **还原地址**：`u` 是相对路径就拼 `WM_IMAGE_GALLERY_BASE`；是完整链接就照用；都不是回 400。
3. **取图**：`fetch`，只发 GET，不带读者的任何请求头（Cookie、Authorization、Referer、X-Forwarded-*），`redirect: 'manual'`，3xx 当失败；单张上限 5 MB（按流读，超了就断）；10 秒超时；同时进行的代取最多 8 个，超了回 503。`WM_OUTBOUND=off` 时不发起，回 503「图片暂不可用」。
4. **回给浏览器**：上游的 `Content-Type` 是 `image/png`、`image/jpeg`、`image/webp` 之一（Q4：GIF、SVG 不收），否则回 415（为了不让市场同源上被打开的「图片」变成网页）；宽高从文件头纯解析（PNG 的 IHDR、JPEG 的 SOF、WebP 的 VP8/VP8L/VP8X），对不上声明的类型回 415 `image_unreadable`，像素超过 4000 万回 502 `image_too_many_pixels`（Q2）。响应头：`X-Content-Type-Options: nosniff`、`Content-Security-Policy: default-src 'none'; sandbox`、`Cache-Control: private, max-age=300`、`Referrer-Policy: no-referrer`。
5. **缓存**：进程内按完整地址缓存 5 分钟、合计不超过 64 MB；命中缓存前照样先判权（第 1 条）。
6. **唯一保留的一条防护**：解析出的地址只要有一个不是公网就不取（回 400）。分类复用 `server/src/url-admission.ts` 的 `classifyV4`、`classifyV6`，只认 public 一档：回环、私网、链路本地（含云元数据 169.254.169.254）、CGNAT 100.64/10、文档与基准网段、组播、IPv6 的 2000::/3 以外、映射到这些的 `::ffff:` 地址都不取。**唯一例外是配置的图库前缀**：只认完整链接落在 `WM_IMAGE_GALLERY_BASE` 前缀下，不认图库那台主机。判过的地址直接当连接地址用（给 HTTP 请求一个自定义 `lookup`），取的时候不再解析，防 DNS 重绑定；几行代码，不引依赖。理由：这条保护的是市场自己和内网里的其它服务（控制面、凭据库），不是图片；不做的话，任何能看台的人都能借这条路由读本机的管理接口。属主要是连这条也不要，评审时提出来就删。（D5 定钉址为可选；本规格做了。）

## 七、用例（先红后绿）

1. 写 `image` 列：完整链接、配了前缀时的相对路径都能写；`ftp://`、`javascript:`、含 `..` 的相对路径、没配前缀时的相对路径、超长都报 400。
2. 代取判权（按引用判）：匿名 401；管理口令 403；跨站 403；台上没有授予的人、只有 `report-read` 或 `report-respond` 的人（读不了视图）都 403；来源视图不在路径里的台、视图里没有这条链接、视图不存在、视图不显示图片列、版本不存在都 403——以上**图库收到的请求数都为 0**；有 `render` 且视图引用了的照取；授予收回后，或换一份不显示这张图的视图，即使这张图在缓存里也 403。
3. 代取结果：图库返回 PNG → 200 且字节一致；JPEG、WebP（VP8X、VP8L）→ 200；GIF、`text/html`、头写 PNG 内容不是 PNG → 415；超过 4000 万像素 → 502；返回 302 → 502；超过 5 MB → 502；超时 → 504；`WM_OUTBOUND=off` → 503。
4. 防护那一条：`http://127.0.0.1:<控制面端口>/…`、`http://169.254.169.254/`、`http://10.0.0.1/`、`http://[::1]/`、文档网段 `http://192.0.2.1/` → 400；图库前缀下 → 放行；同主机、前缀外的路径不算例外；公网 IPv4、IPv6 放行，ULA、映射到私网的 `::ffff:` 地址、基准网段、组播都拒。
5. 不转发：图库收到的请求里没有读者的 Cookie、Authorization、Referer。
6. 缓存：第二次取不再请求图库；没权限的人在缓存命中时仍是 403。
   另：DNS 重绑定（判时公网、连时回环）不访问回环服务；解析结果公网与回环混合时 400；解析超过 10 秒、持续滴字节超过 10 秒都 504；`image/svg+xml` 415；图库前缀下的完整链接同样不许 `..`、`%2f` 拐出前缀。
7. 视图（查询期校验，与第五节一致）：`image` 列按值筛选（`eq`、`in`、`contains`、`prefix` 等）、排序、分组、`min`/`max`/`sum`/`avg` 报 400；判空（`is_null`、`not_null`）、`count`、`count_distinct`、选出来照常。
8. 报告：`image` 节点引用参数、字段、数据行都能冻结出链接加哈希；报告作来源时同样按引用判；引用的列不是 `image` 类型时编译报错；报告页显示走代取路由；只有 `report-read` 的读者从报告页实际加载到图。注意现行 `report-compile.ts` 的模板参数只认 `month`、槽列类型没有 `image`，PR C 要补参数与槽列的类型契约，不能只删拒 image 节点的那一行。 PR C 验收另补：读报告时按冻结的哈希核对取回的图，**哈希不符就显示「图片已变」占位、不显示新图**；哈希相符照常显示。
   落实（PR C）：模板参数类型 `month`、`image` 两种，槽列多 `image`；节点写成 `{ id, type: 'image', src: <一个引用>, alt: 1～200 字 }`，引用 `month` 参数或非 image 列报 `image_source_type`，值不是合规链接报 `invalid_image_ref`；一份报告最多 20 个图片节点，不能放进栅格。生成时每张图经代取同一处取一次、记 sha256，取不到不出报告（`report_image_unavailable`）。代取路由带 `report=<编号>` 时按报告作来源判（`report-read`、报告属于这个台、冻结正文里有这条链接），取回的图哈希不符回 409 `image_changed`，报告页显示「图片已变」。
9. 页面：表格和记录卡里图片列出缩略图；取不到显示占位；单测核源码里没有内联样式和写死的颜色。

测试用合成数据和一个测试脚本自己在本机回环上起的假图库，不碰外网。
