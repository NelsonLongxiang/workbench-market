# 图片 · 第 1 步实施规格

状态：实施规格，待评审。依据：设计稿 [docs/image-support-design.md](image-support-design.md)（#1002、#1003、#1004，release/10 已合入 `36ffa021`）和属主 2026-11-23 在 UI/UX 席会话里的四句话（见第一节，**均为 UI/UX 席转述**）。代码基线：release/10 `752b0a21`。哪些可以先开工、哪些要等属主定，见第六节。

## 一、属主已定（转述，不再讨论）

| # | 属主原话 | 落到本规格 |
|---|---|---|
| D1 | 「图片只支持链接吧，但是，不经由浏览器访问，由工作台市场统一处理，我会准备一个本地的图库提供本地访问地址」 | 只存链接，不收上传、不存原图；浏览器只请求市场的代取地址，由市场去取图 |
| D2 | 「无需凭据，就是静态资源链接」 | 市场访问图库不带凭据 |
| D3 | 「还有一些图片链接是公网的」 | 链接可以是图库地址，也可以是公网地址 |
| D4 | 「这块的资源不需要考虑。那么多安全措施。不影响」 | 图片按非敏感资源处理：公网链接直接收、不设域名白名单（设计稿 Q13、Q16 已定）；设计稿第 3 节 W 表里的成套安全措施不在第 1 步实现。**D4 说的是安全措施，不是逐项裁定功能取舍**：冻结怎么存、谁能看、图库可见范围这些仍是设计稿里的待定项，本规格第六节只给作者的从简默认 |

设计稿里仍待定的项，本规格取作者的从简默认（第六节），**不是属主逐项裁决**；属主改任何一项，实现跟着改。设计稿已定的 Q11「图库不要凭据」照旧沿用其前提：图库与市场同机、只绑本机回环；异机部署要属主另行确认。

## 二、这一步做什么、不做什么

做：

- 数据视图：数据集加一种列类型 `image`，格子里存一个图片链接；`table` 和 `records` 两个块把它显示成缩略图，点开看原图。
- 报告：模板第 2 版加 `image` 节点，图片链接来自模板参数、字段或数据行；冻结时怎么存见第六节 Q3/Q14（作者默认：只记链接）。
- 代取：一条服务端路由，按「这个人能看这个台」放行，然后由市场去取图交给浏览器。

不做：上传；表单（form 块）填图；图片编辑；报告导出 PDF（现在本来就没有 PDF 服务）；按台隔离图库目录。

## 三、链接和配置

- 新环境变量 `WM_IMAGE_GALLERY_BASE`（可选）：图库的地址前缀，例如 `http://127.0.0.1:8090/`。按仓库红线写进 README。
  - 配了：格子里可以写图库内的**相对路径**（不以 `http://`、`https://` 开头的），代取时拼在这个前缀后面。图库搬家只改配置，不改数据。
  - 没配：只收完整的 `http(s)://` 链接，相对路径写入时报错。
- 格子的值：文本，最长 2048 个字符；只认两种写法——`http://` 或 `https://` 开头的完整链接，或（配了前缀时）不含 `..` 段、不以 `/` 开头的相对路径。其余写入时报 400「图片须为 http(s) 链接或图库内的相对路径」。
- 浏览器拿到的永远是市场自己的地址：`/api/bench-views/<台>/image?u=<格子里的原值，URL 编码>`。

## 四、代取路由

`GET /api/bench-views/:bench/image?u=…`。**不新增动作**：路由照这组路由的注册写法声明 `{ action: 'bench-store.render', kind: 'read', statusNotVerdict }`，处理里照报告跨台列表（`/api/report-subjects/:subject`）的写法自己判，动作清单、预设、角色矩阵都不改。

1. **判权**（顺序固定）：`who(req, res)` 认人（跨站 403、管理口令 403、匿名 401）→ 取台登记 → `may(actor, 'bench-store.render', 台) || may(actor, 'bench-store.report-read', 台)`，两项都不成立统一回 403 → 台没登记的，判过权才回 404 → 之后才查缓存、去取图。**不能用 `allowActor`**：它按传入的单个动作判权、失败直接回 403，用 `render` 调会在 OR 之前挡掉只读报告的人。没权限的请求不发起任何外部请求。
2. **还原地址**：`u` 是相对路径就拼 `WM_IMAGE_GALLERY_BASE`；是完整链接就照用；都不是回 400。
3. **取图**：`fetch`，只发 GET，不带读者的任何请求头（Cookie、Authorization、Referer、X-Forwarded-*），`redirect: 'manual'`，3xx 当失败；单张上限 5 MB（按流读，超了就断）；10 秒超时；同时进行的代取最多 8 个，超了回 503。`WM_OUTBOUND=off` 时不发起，回 503「图片暂不可用」。
4. **回给浏览器**：上游的 `Content-Type` 是 `image/png`、`image/jpeg`、`image/webp`、`image/gif` 之一就原样转出，否则回 415（为了不让市场同源上被打开的「图片」变成网页）。响应头：`X-Content-Type-Options: nosniff`、`Content-Security-Policy: default-src 'none'; sandbox`、`Cache-Control: private, max-age=300`、`Referrer-Policy: no-referrer`。
5. **缓存**：进程内按完整地址缓存 5 分钟、合计不超过 64 MB；命中缓存前照样先判权（第 1 条）。
6. **唯一保留的一条防护**：解析出的地址只要有一个不是公网就不取（回 400）。分类复用 `server/src/url-admission.ts` 的 `classifyV4`、`classifyV6`，只认 public 一档：回环、私网、链路本地（含云元数据 169.254.169.254）、CGNAT 100.64/10、文档与基准网段、组播、IPv6 的 2000::/3 以外、映射到这些的 `::ffff:` 地址都不取。**唯一例外是配置的图库前缀**：只认完整链接落在 `WM_IMAGE_GALLERY_BASE` 前缀下，不认图库那台主机。判过的地址直接当连接地址用（给 HTTP 请求一个自定义 `lookup`），取的时候不再解析，防 DNS 重绑定；几行代码，不引依赖。理由：这条保护的是市场自己和内网里的其它服务（控制面、凭据库），不是图片；不做的话，任何能看台的人都能借这条路由读本机的管理接口。属主要是连这条也不要，评审时提出来就删。（设计稿 #1004 2.7 把钉址列为「从简不做」，本规格选了做，差异请属主在决策卡上一并定。）

## 七、用例（先红后绿）

1. 写 `image` 列：完整链接、配了前缀时的相对路径都能写；`ftp://`、`javascript:`、含 `..` 的相对路径、没配前缀时的相对路径、超长都报 400。
2. 代取判权：匿名 401；管理口令 403；跨站 403；台上没有授予的人、只有 `report-respond`（回应报告）的人都 403，且**图库收到的请求数为 0**；只有 `render` 的人、只有 `report-read` 的人都能取到；授予收回后，即使这张图在缓存里也 403。
3. 代取结果：图库返回 PNG → 200 且字节一致；返回 `text/html` → 415；返回 302 → 502；超过 5 MB → 502；超时 → 504；`WM_OUTBOUND=off` → 503。
4. 防护那一条：`http://127.0.0.1:<控制面端口>/…`、`http://169.254.169.254/`、`http://10.0.0.1/`、`http://[::1]/`、文档网段 `http://192.0.2.1/` → 400；图库前缀下 → 放行；同主机、前缀外的路径不算例外；公网 IPv4、IPv6 放行，ULA、映射到私网的 `::ffff:` 地址、基准网段、组播都拒。
5. 不转发：图库收到的请求里没有读者的 Cookie、Authorization、Referer。
6. 缓存：第二次取不再请求图库；没权限的人在缓存命中时仍是 403。
   另：DNS 重绑定（判时公网、连时回环）不访问回环服务；解析结果公网与回环混合时 400；持续滴字节超过 10 秒 504；`image/svg+xml` 415；图库前缀下的完整链接同样不许 `..`、`%2f` 拐出前缀。
7. 视图：`image` 列拿来筛选、排序、聚合报错。
8. 报告：`image` 节点引用参数、字段、数据行都能冻结出链接；引用的列不是 `image` 类型时编译报错；报告页显示走代取路由；只有 `report-read` 的读者从报告页实际加载到图。注意现行 `report-compile.ts` 的模板参数只认 `month`、槽列类型没有 `image`，PR C 要补参数与槽列的类型契约，不能只删拒 image 节点的那一行。
9. 页面：表格和记录卡里图片列出缩略图；取不到显示占位；单测核源码里没有内联样式和写死的颜色。

测试用合成数据和一个测试脚本自己在本机回环上起的假图库，不碰外网。
