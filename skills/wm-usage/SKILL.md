# 使用工作台市场

登录后，从「工作台市场」 `/market` 打开卡片。卡片上的「打开」进入 `/use/<卡片编号>`。新台默认使用数据视图：在页签切换视图、用筛选栏选条件，在配置好的表单填写并提交。外部服务和自产页按卡片提供的入口打开。

- **报告**：支持报告的台首页有「报告」入口。打开列表 `/use/<卡片编号>/reports` 或用 `?report=<报告编号>` 直达一份。报告保存生成当时的数据，原数据更新后不会改写它。在有权的报告页可以对论断认可、反驳或补充。
- **驾驶舱**：在 `/cockpit` 打开自己的看板，可组织多块已获访问权限的内容。
- **SOP 台**：按当前运行的步骤填数据或提交附件，从运行页看状态和回执。
- **自产台**：通过台内控件提交表单、上传和下载文件。

## 给席位接入能力

席位先用 `access_info` 查工具和能力目录，用 `access_info { "tool": "工具名" }` 或能力详情读参数表。按用途申请必要的台、对象和动作，等有权人批准后再按目录调用。数据视图读写授予限定到台。详细路径见 [wm-capability-access](../wm-capability-access/SKILL.md)。

## 属主从终端使用个人令牌

1. 用属主账号打开市场设置的「个人令牌」，填名称、作用域、可用台和有效期。有效期默认 30 天，可选 1～90 天。保存成功时原文只显示一次。将原文存入本人已有的 0600 普通文件。
2. 在 `bin` 已加入 PATH 的环境导入。把地址换成市场的 HTTPS 地址，把示例台标识换成签发时选定的台。

```sh
wm user login --token-file ./private-token --url https://market.example
wm user reports demo --subject item:123
```

导入会保存一份权限为 0600、绑定该市场来源的本机配置。用 `wm user --help` 查完整参数。按用途选作用域：`bench:read`（查询、读报告）、`bench:write`（建数据集、写行）、`view`（保存视图）、`grants`（MCP 授予）、`report-dimensions`（报告维度治理）。按台操作必须选台；仅使用报告维度治理时可不选台，绑定到台仍须选目标台。市场继续按当前属主身份和业务规则判权。

- 返回 403 时，核对命令、作用域、可用台与业务权限。
- 返回 401 时，检查令牌是否到期或已撤销，以及配置是否对应当前市场。需要继续使用时按授权重新签发。
- 不再使用时，在市场设置撤销令牌，再移除不再需要的本机配置。撤销会立即使该令牌无法认证。

## 打不开时

先确认登录身份有权访问这张卡片，并核对卡片是否在线。自产页白屏时把台标识和现象交给维护者，供其按 [wm-market-guide](../wm-market-guide/SKILL.md) 排查资源路径和 sandbox。
