# 工作台市场·如何使用（用户视角 5 分钟）

市场首页 = http://<host>:9800/ 。三件东西：工作台（外部登记+自产台）、驾驶舱（看板）、技能市场。

## ① 浏览与打开
- 首页卡片即全部工作台（状态绿=在线）；点击进入 `/use/<id>` 使用页（门户 iframe 代理·自动处理登录）
- 直连入口：使用页右上「新窗口」；统一门户路径 `/go/<id>/`
## ② 提交数据（表单）
- 自产台页面填表提交 → 数据落库（`POST /api/apps/<slug>/data`）·提交即回铃绑定 agent
## ③ 上传/下载文件
- 台内上传控件（multipart）·带 note 备注 → 列表即显 name/url/note/时间
- 下载：点文件链接（`/api/apps/<slug>/files/<id>`）
## ④ 驾驶舱（可视化）
/cockpit 拖拽面板·每面板内嵌一台·统计卡/图表；布局可存
## ⑤ SOP 台（流程执行）
按步骤页走：填数据/传附件/看执行态；run 结束封存可回看
## 常见问题
- 白屏→硬刷新（Ctrl+F5）；要口令→顶栏钥匙图标输入管理员口令；连不上→查台是否在线（卡片状态）


## 白屏常见原因速查（补充 sandbox 类）

| 现象 | 原因 | 处置 |
|---|---|---|
| 整页白板 | 资源根路径未带 /go/<id>/ 前缀 | 平台已改写（白屏五层）；自拼绝对路径会逃逸 |
| 页面在、样式/脚本全丢 | 页面是**不透明源**（自产台 sandbox），子资源被外壳拦 | 打包成**单文件**（内联 css/js）最稳 |
| 页面在、表单提交无效 | sandbox 页面调本台 data/files 未带 `X-App-Token` | 读 `window.WM_APP_TOKEN` 随请求带出（#198） |
| 强制刷新后仍白 | 先看控制台：`Origin: null`/`ERR_BLOCKED_BY_CLIENT` = sandbox 类，不是缓存问题 | 按上两行处置 |
